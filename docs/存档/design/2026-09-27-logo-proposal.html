青鸟 Git · Logo 重设计

朱砂印章换掉，换成几何

印章的圆角、衬线、印泥红都属于「纸墨」那一套，放在 10 级中性灰里就像一件旧家具没搬走。 新的 logo 全部用单一颜色 + 纯几何 + 圆头笔画，并且优先用界面主色 #0D9488， 这样它和同步环、状态点、按钮属于同一套语言。

放进真实位置

同一个形状要在 16px 托盘图标、20px 标题栏、34px 导航轨、256px 安装图标里都成立。

标题栏（20px）

青鸟 Git

标题栏文字同时从思源宋体换成无衬线（Outfit / 系统中栈）——衬线字属于纸墨体系，和新 logo 一样要一起换掉。品牌感靠 logo + 字重建立，不靠字体。

导航轨顶部（34px 圆角方块）

logo 在轨道最上方，不再兼任侧栏开关。开关改用标准 panel 图标——原来「印章 hover 变面板」的双层技巧是纸墨风格的小聪明，新体系里靠位置和图标本身说话就够了。

拍板

1

选哪个方案？

我推荐 A 环中枝：它和同步环是同一个形状，用户看 logo 就能预告界面的核心交互；且形状足够简单，托盘 16px 也不糊。B 更有品牌个性但小尺寸吃亏，C 最清楚但没辨识度。

建议 A，若更看重"青鸟"的品牌感则选 B
2

标题栏品牌文字保留「青鸟 Git」四个字吗？

我的建议是保留但换字体——思源宋体 → 无衬线，字重 600，字号 13px。品牌名是既有资产，logo 负责图形识别，文字负责说清是什么，两者不冲突。

建议：保留文字，只换字体与字重
3

配色沿用界面主色 #0D9488，还是单独给 logo 一个色？

沿用主色能让 logo 和界面属于同一套系统；单独给色（比如更亮的青）会让 logo 更跳，但多一个色就要多一套维护规则。

建议：沿用 #0D9488，不新增品牌色
